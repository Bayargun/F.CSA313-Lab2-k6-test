## Дүгнэлт

Туршилтаар k6 ашиглан 5, 30, 100 VU ачаалал өгч системийн ажиллагааг туршиж үзлээ. 5 VU үед p95 latency 308.14 ms, throughput 7.3 req/s байсан. Мөн бүх тестийн error rate 0.00% байсан учраас 100 VU хүртэл сервер ачааллыг асуудалгүй дааж байна гэж үзсэн. 30-аас 100 VU хүртэл p95 бараг өөрчлөгдөөгүй тул хэрэглэгчийн туршлага муудсан тодорхой цэг энэ туршилтаар ажиглагдсангүй. 5 VU-ийн p95 болох 308.14 ms-ийг baseline болгон авч, түүнээс 1.5 дахин их буюу p95 < 462.21 ms гэсэн SLO тодорхойлсон. Мөн error rate 1%-иас бага байх шаардлага тавьсан. Энэ ажлаар ачаалал нэмэгдэх үед throughput болон latency хэрхэн өөрчлөгддөг, мөн baseline хэмжилтэд үндэслэн SLO тодорхойлж болдгийг ойлгож авлаа.
